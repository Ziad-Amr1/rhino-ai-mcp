Rhino 3D MCP server connects AI clients to McNeel Rhinoceros 3D (Rhino 8 & 9). Use read-only tools (rhino_get_connection_status, rhino_get_document_info, rhino_list_layers, rhino_query_objects, rhino_get_selected_objects) to inspect models, layers, and objects. Use rhino_execute_python to run RhinoCommon or rhinoscriptsyntax code. Use rhino_create_geometry and rhino_run_command to generate models and execute Rhino commands.
